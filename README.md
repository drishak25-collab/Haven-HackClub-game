# Trashlight

A gritty 2D adventure platformer made in Godot for Hack Club. Dash through industrial ruins, escape rising sludge, and survive the Foreman's orbital strikes, spike storms, and explosions. Includes Easy and Hard modes and a boss practice button. Death restarts the adventure; reaching the final boss is the only checkpoint.

## Complete source

Download **[Trashlight-Public-Source.zip](Trashlight-Public-Source.zip)** and extract it. It contains the complete project: scripts, scenes, levels, sprites, audio, screenshots, and licenses. Import the extracted `project.godot` in **Godot 4.5.1**, then press F5.

## Controls

- A/D or arrow keys: move
- Space/W/Up: jump
- Shift/C: dash
- X/E: lantern pulse
- Escape/P: pause
